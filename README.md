# 海钓日和

在船上和朋友一起钓鱼的 3D 小游戏，浏览器里直接玩。

**在线玩：https://taojr.github.io/haidiao/**

## 怎么玩

- 选 Tao 或 Lulu 出海，另一个人由电脑陪钓。
- 只用一个键（鼠标、触屏或空格）：按住蓄力，松开抛竿；咬钩时快按；按住收线，鱼线太紧就松手。
- 海鸥聚集的地方有鱼群，把饵抛到鸟群下面，咬钩更快、鱼更大。
- 大鱼拉到船边要另一个人下抄网：对方的按钮变绿时按下（或按 F）。
- 每局 5 分钟，最大的一条鱼赢得彩池。

## 两个人一起玩

打开页面后点"复制邀请链接"发给对方，对方打开就上船，不需要注册或登录。两边是浏览器之间直接连接，个别校园网或公司网可能连不上。

## 本地运行

```bash
python3 -m http.server 8765
```

然后打开 http://localhost:8765 。

## 技术

Three.js 卡通渲染，海面和天空是自写着色器；音效用 WebAudio 合成；联机用 PeerJS（WebRTC）。没有构建步骤，也没有图片或音频素材文件。
